# Estudos Rust

Repositório pessoal de estudos, pequenos experimentos e algoritmos em Rust.

## Conteúdo
- `treinamento-rust`: primeiros passos, I/O no terminal e cálculo de idade.
- `log-entry`: structs e filtragem de logs.
- `referencias-borrowing`: testes com referências e ponteiros.
- `structs-tuplas`: testes com structs, tuplas e tipos primitivos.
- `estudos-algoritmos`: implementação de algoritmos de ordenação (Selection Sort).
- `terminal-animation`: animação interativa no terminal usando threads e atomics.
